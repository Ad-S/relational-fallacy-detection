# Detecting Cross-Turn Rhetorical Fallacies in Discourse

Motte-and-bailey and strawman detection as **cross-turn claim-pair classification** on r/ChangeMyView
(ConvoKit Winning Arguments corpus). Each example is a pair of claims A and B (plus the intervening
challenge C for motte-and-bailey); each fallacy is its own binary task against NONE.

Advanced NLP, Monsoon 2026, IIIT Hyderabad (team random.string).

## Dataset

`data/annotations/dataset_augmented_all_v2.csv`: 683 claim pairs.

| Source | Rows | Labels |
|---|---|---|
| Real CMV pairs, hand-labeled (`consolidate_v2.py`) | 188 | human |
| Hand-written examples | 20 | human |
| Generated variants of the above (paraphrase, topic transfer, label flip) | 475 | generated (`label_verified=False`) |

Claims were extracted from the raw comments with Claude Sonnet 5 (interactive, not scripted). Variants were
generated with Claude Sonnet 5.5 in isolated, tool-less sessions (`src/augmentation/`). Every variant
carries its source example's `conversation_id`, so grouped cross-validation keeps an example and its
variants in the same fold.

## Reproducing the results

Local (CPU) steps, from the repository root with `pip install -r requirements.txt`:

```bash
python src/annotation/consolidate_v2.py                 # 188 real labeled pairs
python src/annotation/build_dataset_final_v2.py         # + 20 hand-written
python src/augmentation/collect_accepted.py --set handwritten --accept-all
python src/augmentation/collect_accepted.py --set real --accept-all   # -> dataset_augmented_all_v2.csv
python src/features/specificity_features.py data/annotations/dataset_augmented_all_v2.csv
```

GPU steps (run on Jarvislabs with the `jl` CLI; each bundle is uploaded as a directory):

```bash
cd finetune   && jl run . --script run_session.py --gpu H200 --pause -- --hours 5
cd llm_bundle && jl run . --script llm_session.py --gpu H200 --pause -- --hours 2.5
cd finetune   && jl run . --script train_cv.py --gpu H200 -- --data data/dataset_augmented_all_v2.csv \
                   --eval_sources reddit_cmv,handwritten --tag nli_pair_orig_only
```

Analysis (local, after downloading the GPU results into `finetune/session_results/` and `llm_bundle/llm_results/`):

```bash
python src/models/xgb_grouped.py
cd src/analysis && python final_results.py && python llm_results.py && python orig_only.py && python paper_figures.py
```

## Evaluation protocol

- One binary classifier per shape; StratifiedGroupKFold (5 folds) grouped by conversation; 3-5 seeds.
- All trained models (XGBoost, fine-tuned DeBERTa variants) use identical fold assignments.
- Fine-tuned models are scored on the original test input and with the selection trigger phrases removed
  from claim B (`finetune/triggers.py`).
- Confidence intervals: cluster bootstrap over conversation groups.

## Models

- XGBoost on 6 NLI + 5 lexical features (`MoritzLaurer/DeBERTa-v3-large-mnli-fever-anli-ling-wanli`, frozen).
- Fine-tuned cross-encoders: DeBERTa-v3-large initialised from the NLI checkpoint, from `microsoft/deberta-v3-large`,
  and a B-only ablation. RoBERTa-large-MNLI was attempted but diverged (NaN predictions) and is excluded.
- Zero-shot: Qwen2.5-7B-Instruct and Qwen2.5-32B-Instruct (vLLM, temperature 0); Claude Opus 5.5 on the 111 original
  examples of the mid-term dataset (`presentation_figures/llm_rerun/`).
- Two-stage pipeline: an LLM extracts the claim B attributes to (strawman) or denies about (motte-and-bailey) A's
  author; the frozen NLI model tests whether A entails it.

No models were uploaded to HuggingFace or WandB.
